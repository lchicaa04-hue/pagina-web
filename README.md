# Página web Tú y Yo

Landing page oficial del cortometraje animado 3D **Tú y Yo**, desarrollada con HTML, Tailwind CSS CDN, Google Fonts y Lucide Icons.

## Design System

La interfaz usa una identidad visual cozy y romántica:

- **Primary:** `#FFD1DC`
- **Secondary:** `#FFF9F5`
- **Accent:** `#E75480`
- **Dark main:** `#FFF0F5`
- **Border:** `#FFC0CB`
- **Tipografía de títulos:** Playfair Display
- **Tipografía manuscrita:** Great Vibes
- **Tipografía de interfaz:** Quicksand
- **Componentes:** tarjetas redondeadas de 20px, bordes rosa y sombras suaves
